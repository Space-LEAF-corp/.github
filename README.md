1. Mission Purpose
The JarvondisU Cadet Program is a browser-native, zero-trust learning environment designed for children ages 6-17. It provides a safe, observable, parent-approved digital campus where cadets progress through missions, stewardship layers, and skill domains. The pilot validates operational readiness for district adoption, accreditation, and sovereign-safe deployment.
2. What Exists Today (Operational Baseline)
▪ FAAO Zero-Trust Architecture
Live posture checks, token validation, domain switching, metadata protection.
▪ Security Classroom (GO Domain)
Four FAAO simulators: Token Builder, Domain Switch Trainer, Device Posture Checker, Metadata Leak Detector.
▪ Teacher Oversight Dashboard
Live crew locations, mission flags, per-student session data, FAAO compliance, role-based logs.
▪ Cadet Mission Engine
Five curriculum missions using real FAAO calls and observable progress gates.
▪ Traceability Registry v0.2.0
Requirements → Capabilities → Systems → Interfaces → Artifacts → Controls → Tests → Evidence.
▪ Parent Approval Loop
Time-boxed sessions, full visibility, no tracking, no metadata harvesting.
▪ Sovereign Mission Core
Stewardship doctrine, seals, and safety logic for civilian-first learning.
